# Architecture Decision Records (ADRs)

This folder contains architectural decision records for the Docodylus project, written in [MADR format](https://adr.github.io/madr/).

## Guidelines

- Each ADR is stored in a separate Markdown file.
- Filenames follow a `NNNN-title.md` convention (e.g., `0001-define-adr-structure.md`).
- Metadata is provided in frontmatter: `status`, `date`, and optional `tags`.
- ADRs are included in the [project documentation](../index.md) and visible through the MkDocs site.

For the rationale behind this structure, see [ADR 0001](0001-define-adr-structure-and-format-for-project.md).
